Mock CRM API

Fake CRM records for Genesys Cloud IVR and bot demos. Look a caller up by phone number and get back whichever fields you choose below. No authentication, CORS wide open, nothing is written or persisted.

https://—/api/v1/:endpoint
  1. Choose your dataset and tick the fields you want the data action to return — built-in industry, or your own field names.
  2. Try a lookup to see the exact JSON Genesys will receive, including for a number that does not exist.
  3. Download the data action, or build it by hand from the field-by-field sheet if you are teaching.
  4. In Genesys Cloud — Admin → Integrations → add Web Services Data Actions and activate it, then Actions → Import. Test with +966501234001, Save, then Publish. An unpublished action is invisible to Architect.

1 · Choose your dataset and fields

This is where you decide what the data action returns. Pick a built-in industry and tick the fields you want — everything below regenerates as you change it, with no redeploy. Or define your own fields, which needs one paste and a redeploy.

These work immediately — no redeploy. The field spec travels in the request URL and the API generates values from it, so the records below and the data action are live as soon as you type. Values are deterministic: the same caller always gets the same answer, which is what stops a balance changing between two calls in a demo.
Optional — bake these fields into the dataset permanently

Only worth doing if you want hand-written values rather than generated ones. Paste this into netlify/functions/lib/data.mjs inside INDUSTRIES, then redeploy.
